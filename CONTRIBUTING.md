# Contributing to Qwen DianJin

Thank you for your interest in Qwen DianJin. We welcome bug reports,
documentation improvements, tests, and focused code contributions.

## Before contributing

1. Read and follow the [Code of Conduct](CODE_OF_CONDUCT.md).
2. Search existing issues and pull requests before opening a new one.
3. For substantial changes, open an issue first and agree on the scope with
   the maintainers.
4. Do not submit confidential information, personal data, credentials,
   proprietary datasets, or material you are not authorized to contribute.

## Contributor License Agreement

Before a contribution can be merged, the contributor must sign the
applicable Alibaba Contributor License Agreement (CLA), or confirm an existing
valid CLA signature through the repository's CLA check when requested.
Contributors must use the same verified identity associated with their CLA.

By submitting a contribution, you represent that you have the right to submit
it and that doing so does not violate any third-party rights, confidentiality
obligations, or applicable laws.

## Pull request process

1. Fork the repository and create a focused branch.
2. Keep each pull request limited to one logical change.
3. Add or update tests and documentation where applicable.
4. Run the relevant tests and formatting checks for the affected subproject.
5. Confirm that no secrets, personal data, local paths, generated files, or
   unauthorized materials are included.
6. Describe the change, its motivation, test evidence, and licensing impact
   in the pull request.

Maintainers may request changes, additional provenance, or legal review before
accepting a contribution.
